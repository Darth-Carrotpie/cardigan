# Insert smart chips and building blocks in your Google Doc (Google Docs Help)

> Source: https://support.google.com/docs/answer/10710316?hl=en
> Collected: 2026-10-31
> Published: Unknown
> Author: Google
> Type: official-docs

## Excerpts

> You can put smart chips in your Google Doc to add details about:

> Dates or Google Calendar events

> You can also insert placeholder chips, time trackers, and dropdowns

> use building blocks to track projects, files, and more.

> To add a people smart chip, start typing the name or email address of the person you want, or type `@me` to add yourself.

> To add a file smart chip, enter the file name or related keywords.

> You can add a smart chip for a Calendar event to see information about the event

> To add a smart chip that a collaborator can fill in, select "Placeholder chip."

> When you mention another user in a smart chip, they don't automatically get access to your document.

> To grant access to another user, you must share your document.

## Collector's note

Replaces copy-pasting attendee lists, file links and event details into docs, and hand-built status tables (via dropdown chips and building blocks such as project trackers). Caveat: mentioning someone does not share the doc with them. The fetched page did not include detail on the meeting-notes building block itself (Calendar "Take meeting notes" pre-fills a Doc from the event) — not verified from official text here.
