# Sort & filter your data (Google Docs Editors Help)

> Source: https://support.google.com/docs/answer/3540681?hl=en
> Collected: 2026-10-31
> Published: Unknown
> Author: Google
> Type: official-docs

## Excerpts

> On a computer, you can filter data so the filtered data only applies to your view of the spreadsheet.

> When you add a filter, anyone with access to your spreadsheet will find the filter too.

> Let multiple people find different filter views at the same time.

> you can create a temporary filter view that only you can use. Your filter view won't be saved.

> To save your filter view, at the top right, click Save View.

> Apply the filter view [...] Copy the URL [...] Share the filter view link

> You can only apply one filter view at a time.

> You can't change the order of filter views.

## Collector's note

Replaces making per-person or per-team copies of a spreadsheet ("Sales_v2_Anna.xlsx") and emailing filtered extracts: a saved filter view gets its own shareable link over the single live sheet. Caveat: one filter view at a time; view-only users only get temporary views. For cardigan, "share a filter-view link" is the native alternative to building a separate report tab or export.
