# Create an approval (Microsoft Support, Teams)

> Source: https://support.microsoft.com/en-us/office/create-an-approval-6548a338-f837-4e3c-ad02-8214fc165c84
> Collected: 2026-10-31
> Published: Unknown
> Author: Microsoft
> Type: official-docs

## Excerpts

> Open the Approvals app in Microsoft Teams.

> Select New approval request.

> Fill in the name of the request, who needs to approve it, decide approval order

> any additional info, and add an attachment if needed.

> Select Send. You'll be able to view the request later by selecting Sent in the hub.

> Approvals you create through Power Automate will appear in the hub, too.
