# Approvals

> Sources: Microsoft Support, undated

> Updated: 2026-10-31

## Overview

The email asking for approval, its reply-all chasers and the side spreadsheet that tracks who signed off can be replaced by a built-in approval request: one form naming the item, the approvers and their order, with sent requests viewable later in a hub. The evidence is a thin vendor help page that describes the steps but not plan eligibility.

| Manual deliverable | Native feature (tool) | Plan/licence caveat |
|---|---|---|
| Approval-request email and chase-ups | Approval request with approvers, approval order and attachment (Microsoft Teams Approvals app) | Not stated on the fetched page; the collector cites an older report on plan coverage, unverified for 2026 |
| Hand-kept sign-off tracker | Approvals hub with Sent view, including Power Automate approvals (Microsoft Teams) | As above |

## Microsoft Teams: Approvals app

Microsoft's support page (official-docs, undated) gives the steps: "Open the Approvals app in Microsoft Teams." "Select New approval request." "Fill in the name of the request, who needs to approve it, decide approval order", then "any additional info, and add an attachment if needed."

The record is kept for you: "Select Send. You'll be able to view the request later by selecting Sent in the hub." Automated approvals land in the same place: "Approvals you create through Power Automate will appear in the hub, too."

## For cardigan

Interpretation, not source claims:

- When a user needs sign-off inside a Microsoft 365 organisation, cardigan suggests an approval request over a drafted approval email, and offers the email only if the approver is outside the tool or the user prefers it.
- The request still needs the never-cut items: what is being approved, by when, the attachment, and any compliance wording. cardigan writes that short request text, not a covering memo.
- A chase-up is unnecessary when the hub shows status; cardigan suggests checking the Sent view before drafting a reminder.
- Plan eligibility is unverified, so cardigan phrases this conditionally (if your organisation has the Approvals app), not as a given.
